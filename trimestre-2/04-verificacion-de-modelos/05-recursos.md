# Recursos complementarios para modelado de funciones

> Este documento recopila una serie de recursos, herramientas y referencias útiles para complementar el aprendizaje autónomo en el área de modelado de funciones, análisis de requisitos y desarrollo de software. Incluye enlaces a plataformas de aprendizaje, canales de YouTube, herramientas técnicas, APIs públicas y recursos para inglés técnico.
